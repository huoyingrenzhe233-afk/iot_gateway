## 1. MQTT 通道(单片机 ↔ 网关)

**topic 约定**:
- 上行(单片机→网关):`dev/mcu01/report`
- 下行(网关→单片机):`dev/mcu01/cmd`

### 1.1 传感器上报(单片机 → 网关)type=sensor

**用途**:单片机每 2 秒采集传感器数据上报。

```json
// topic: dev/mcu01/report
{
  "type": "sensor",
  "dev": "mcu01",
  "ts": "2026-08-12 15:00:00",
  "body": {
    "data": {
      "temp": 25.6,
      "humi": 60.1,
      "light": 320,
      "ir": 2500
    }
  }
}
```

| 字段 | 说明 | 取值范围 |
|---|---|---|
| temp | 温度(温湿度传感器) | 数字,如 25.6 |
| humi | 湿度(温湿度传感器) | 数字,如 60.1 |
| light | 光照(光敏传感器) | 数字,如 320 |
| ir | 红外(红外传感器) | 数字,如 2500 |

**网关处理**:解析 → 更新内存缓存 → `/api/status` 可查到。

**模拟命令**(电脑上测):
```bash
mosquitto_pub -h 192.168.5.70 -t 'dev/mcu01/report' -m '{"type":"sensor","dev":"mcu01","ts":"2026-08-12 15:00:00","body":{"data":{"temp":25.6,"humi":60.1,"light":320,"ir":2500}}}'
```

**预期**:网关日志出现 `mqtt recv dev/mcu01/report:` 和 `device: sensor update temp=25.6 humi=60.1 light=320 ir=2500`;`curl /api/status` 能看到这 4 个值。

### 1.2 命令回执(单片机 → 网关)type=status

**用途**:单片机执行完控制命令后,回报各外设**实际状态**。网关用它校准 `/api/status`(以实际执行为准)。

```json
// topic: dev/mcu01/report
{
  "type": "status",
  "dev": "mcu01",
  "ts": "2026-08-12 15:00:01",
  "body": {
    "items": [
      {"name": "led",      "state": "on", "value": 1},
      {"name": "led_br",   "state": "on", "value": 80},
      {"name": "motor",    "state": "on", "value": 1},
      {"name": "motor_sp", "state": "on", "value": 50},
      {"name": "motor_dir","state": "on", "value": 0},
      {"name": "buzzer",   "state": "off","value": 0}
    ]
  }
}
```

| items[].name | 对应外设 | value 含义 |
|---|---|---|
| led | LED 开关 | 0/1 |
| led_br | LED 亮度 | 0-100 |
| motor | 电机开关 | 0/1 |
| motor_sp | 电机速度 | 0-100 |
| motor_dir | 电机方向 | 0 正 / 1 反 |
| buzzer | 蜂鸣器 | 0/1 |

**可以只回执有变化的项**(部分字段,没列的保持原值)。

**模拟命令**:
```bash
mosquitto_pub -h 192.168.5.70 -t 'dev/mcu01/report' -m '{"type":"status","dev":"mcu01","ts":"2026-08-12 15:00:01","body":{"items":[{"name":"led","state":"on","value":1},{"name":"led_br","state":"on","value":80}]}}'
```

**预期**:网关日志 `device: status receipt led_on=1 led_br=80 ...`;`/api/status` 中 led_on/led_br 变为 1/80。

### 1.3 控制命令(网关 → 单片机)type=cmd

**用途**:Web/Qt 通过 `/api/control` 触发,网关组包后下发。

```json
// topic: dev/mcu01/cmd
{
  "type": "cmd",
  "dev": "mcu01",
  "ts": "2026-08-12 15:00:02",
  "body": {
    "led_on": 1,
    "led_br": 80,
    "motor_on": 1,
    "motor_sp": 50,
    "motor_dir": 0,
    "buzzer": 0
  }
}
```

**单片机收到后**:解析 body 字段 → 执行(LED 亮/电机转/蜂鸣器响)→ 回 1.2 的 status 回执。

**查看下行**(电脑订阅):
```bash
mosquitto_sub -h 192.168.5.70 -t 'dev/mcu01/cmd' -v
```

**预期**:Web 点按钮后,这里能看到完整 cmd 信封。

## 2. HTTP 通道(Web/Qt ↔ 网关)

> ⚠️ HTTP 侧**不用信封**,直接 REST。所有响应 Content-Type: application/json。

### 2.1 健康检查

```
GET http://192.168.5.70:8081/api/health
→ 200 {"status":"ok"}
```
```bash
curl http://192.168.5.70:8081/api/health
```

### 2.2 版本

```
GET http://192.168.5.70:8081/api/version
→ 200 {"version":"1.0.0"}
```
```bash
curl http://192.168.5.70:8081/api/version
```

### 2.3 设备列表

```
GET http://192.168.5.70:8081/api/devices
→ 200 [{"id":"temp_1","kind":"sensor","protocol":"mqtt","description":"温度(温湿度传感器)"}, ...]
```
**返回 7 条**(4 传感器 + 3 执行器)。前端用它动态画卡片。
```bash
curl http://192.168.5.70:8081/api/devices
```

### 2.4 设备状态(Web/Qt 轮询)

```
GET http://192.168.5.70:8081/api/status
→ 200 {"temp":"25.6","humi":"60.1","light":"320","ir":"2500",
        "led_on":1,"led_br":80,"motor_on":1,"motor_sp":50,"motor_dir":0,"buzzer":0}
```
| 字段 | 类型 | 说明 |
|---|---|---|
| temp/humi/light/ir | 字符串 | 传感器值(轮询更新) |
| led_on/led_br/motor_on/motor_sp/motor_dir/buzzer | 数值 | 执行器状态(命令缓存 + 回执校准) |
```bash
curl http://192.168.5.70:8081/api/status
```

### 2.5 控制命令下发(核心)

```
POST http://192.168.5.70:8081/api/control
Content-Type: application/json

{"type":"control","body":{"led_on":1,"led_br":80,"motor_on":1,"motor_sp":50,"motor_dir":0,"buzzer":0}}
→ 200 {"status":"ok"}
→ 400 {"status":"error","message":"missing payload"}   # body 缺失
→ 500 {"status":"error","message":"mqtt not ready"}    # MQTT 未连接
```

**网关处理链**:
1. 解析 body → 组 MQTT 信封(type=cmd)→ 发布 `dev/mcu01/cmd`
2. 同步到状态缓存 → `/api/status` 立即反映(不用等回执)
3. 单片机执行 → 回执校准

**curl 命令**:
```bash
curl -X POST http://192.168.5.70:8081/api/control \
  -H "Content-Type: application/json" \
  -d '{"type":"control","body":{"led_on":1,"led_br":80,"motor_on":1,"motor_sp":50,"motor_dir":0,"buzzer":0}}'
```

**板上验证**(wget,无 curl):
```bash
wget -q -O- --post-data='{"type":"control","body":{"led_on":1,"led_br":80}}' \
  --header="Content-Type: application/json" \
  http://127.0.0.1:8081/api/control
```

## 4. 一键联调测试脚本(全链路)

```bash
# ① 起网关(本机调试)
cd /home/kkk/gateway && ./build/gateway 8099 &

# ② 健康检查
curl http://127.0.0.1:8099/api/health          # {"status":"ok"}
curl http://127.0.0.1:8099/api/version         # {"version":"1.0.0"}
curl http://127.0.0.1:8099/api/devices         # 7 条登记

# ③ 模拟单片机上报传感器
mosquitto_pub -h 127.0.0.1 -t 'dev/mcu01/report' -m '{"type":"sensor","dev":"mcu01","ts":"2026-08-12 15:00:00","body":{"data":{"temp":25.6,"humi":60.1,"light":320,"ir":2500}}}'

# ④ 看状态
curl http://127.0.0.1:8099/api/status          # 应含 temp:25.6 等

# ⑤ 下发控制命令(独立订阅看 MQTT 是否真的发出)
mosquitto_sub -h 127.0.0.1 -t 'dev/mcu01/cmd' -v &
curl -X POST http://127.0.0.1:8099/api/control -H "Content-Type: application/json" -d '{"type":"control","body":{"led_on":1,"led_br":80}}'

# ⑥ 模拟回执校准
mosquitto_pub -h 127.0.0.1 -t 'dev/mcu01/report' -m '{"type":"status","dev":"mcu01","ts":"2026-08-12 15:00:01","body":{"items":[{"name":"led_br","state":"on","value":60}]}}'
curl http://127.0.0.1:8099/api/status          # led_br 应为 60

# ⑦ 收尾:杀进程
pkill -x gateway
```

## 5. 常见坑速查

| 现象 | 原因 | 解法 |
|---|---|---|
| `/api/control` 返回 400 missing payload | 请求体键名不是 `body` | 用 `{"type":"control","body":{...}}`(不是 payload!) |
| `/api/status` 传感器空 | 还没收到上报 | 先 mosquitto_pub 发 sensor |
| 执行器状态和实际不符 | 单片机没回 status 回执 | 确认单片机执行后发回执 |
| MQTT 收不到 | topic 拼错 | 严格用 `dev/mcu01/report` / `dev/mcu01/cmd` |
| 板上 curl 404 | 用了 8080 | 板上是 **8081**(8080 被摄像头占) |
| wget 收不到 | 网关没起 | `ps \| grep gateway` 检查 |

## 6. 信封格式备忘(单片机侧组包对照)

```
通用信封:{type, dev, ts, body}

type: sensor(上报) / status(回执) / cmd(命令) / ack(应答) / ai(AI) / query(查询)
dev:  固定 "mcu01"
ts:   字符串 "YYYY-MM-DD HH:MM:SS"(⚠️ 不是 Unix 秒)
body: 载荷(内容随 type 不同)

命令字段(全部):led_on(0/1) led_br(0-100) motor_on(0/1) motor_sp(0-100) motor_dir(0/1) buzzer(0/1)
```
