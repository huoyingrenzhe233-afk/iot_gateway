## 六、今日踩坑记录(答辩素材)

1. **板子切 WiFi 后 IP 变化**:有线 `192.168.5.70` → WiFi `10.137.31.9`;`~/.ssh/config` 只配了有线 IP,连 WiFi 必须手动 `-i ~/.ssh/id_rsa_gw`
2. **`pkill -f` 会误杀 ssh 会话自身**(命令行含目标字符串),用 `pkill -x gateway` 精确匹配
3. **waitpid 阻塞是事件循环杀手**:子进程卡死不响应 SIGTERM 时,整个网关 HTTP/MQTT/WS 全部停摆,必须有限超时 + SIGKILL 兜底
