## 二、Qt 5.15.2 交叉编译(环境攻坚)

**问题**:宿主机无任何 Qt 开发环境(sysroot 无 Qt 头文件/库/qmake),而板子有 Qt 5.15.2 运行时库。

**方案**:板子 Qt 来源 = buildroot `dl/` 目录的 `qtbase-everywhere-src-5.15.2.tar.xz`,直接用 linaro 工具链手动交叉编译:

```bash
./configure -opensource -confirm-license \
  -xplatform linux-aarch64-gnu-g++ -prefix /opt/qt-aarch64 -release \
  -no-opengl -no-xcb -no-gtk -no-eglfs -no-kms -no-dbus -no-icu \
  -qt-zlib -qt-libpng -qt-freetype -no-fontconfig \
  -nomake examples -nomake tests
make -j8   # 8 核并行,约 40 分钟
```

**关键处理**:
- `/opt` 无写权限(sudo 需密码)→ 用 `make install INSTALL_ROOT=` staging + `bin/qt.conf`(Prefix=..)重定向路径,最终装到 `/home/kkk/qt-aarch64`
- 产出:qmake/moc/uic 工具 + libQt5Core/Gui/Widgets/Network 库 + **linuxfb/vnc 平台插件** + libqjpeg(JPEG 显示必需)

## 六、今日踩坑记录(答辩素材)

1. **交叉编译 Qt 无需 sudo**:`/opt` 无写权限时,`make install INSTALL_ROOT=` staging + `bin/qt.conf`(Prefix=..)重定向即可,不依赖系统目录
2. **板子 busybox tar 不支持 `-z`**:tgz 解压报 "invalid tar magic",改 `gunzip -c | tar xf` 两步解决
3. **板子字体无 emoji**:noto-sans-sc 只有中文,界面 emoji(🎥📡 等)显示为方框 → 全部改为纯文字
4. **Qt VNC 服务器必须收 SetEncodings 才发帧**:客户端只发 FramebufferUpdateRequest 收不到数据(调试中确认)
5. **写脚本批量改字符慎用正则**:`\u1F000` 会被 re 解析为 `\u1F00`+`0` 产生错误范围 `0-\u1FAF`,误删大量字符——用精确字符列表或逐字符判断
